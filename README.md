# Configuration Management


## Description
This repository contains programs that were written during studying university subject "Configuration Management".

### Homeworks
Contains three homeworks: 
1. GUI shell emulator.
2. Git-commits graph visualizator
3. Formal configuration language converter


### Deps
Contains SMT-solution of resolving the package dependencies problem

The dependencies graph is represented with the dictionary

To interact with the solution, you can read [Z3 Docs](https://theory.stanford.edu/~nikolaj/programmingz3.html).
